# awsextras Provider

AWS capabilities that the official AWS provider is missing. The provider is configured as the AWS provider is: a region, a profile, a role to assume, and default tags.

## Resources

| Resource | Gives |
|---|---|
| [`awsextras_lb_listener_rule_priority`](resources/lb_listener_rule_priority) | a free priority for a load balancer listener rule, allocated from a range once and kept |

## Example Usage

```terraform
terraform {
  required_providers {
    awsextras = {
      source = "litebitus/awsextras"
    }
  }
}

provider "awsextras" {
  region = "us-west-2"

  assume_role {
    role_arn     = "arn:aws:iam::000000000000:role/mock-role"
    session_name = "mock-session"
  }

  default_tags {
    tags = { owner = "mock-team" }
  }
}
```
